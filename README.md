# NASA APOD Explorer

A colorful and responsive NASA Astronomy Picture of the Day (APOD) website.

## About

NASA APOD Explorer fetches NASA's Astronomy Picture of the Day using the NASA APOD API and displays the daily space image or video along with its title and explanation.

## Features

- Fetches the latest NASA APOD
- Displays the APOD title and explanation
- Supports NASA image/video content
- Responsive design
- Custom HTML, CSS, and JavaScript interface
- Interactive and colorful space-themed UI

## Technologies Used

- HTML
- CSS
- JavaScript
- NASA APOD API
- Vite
